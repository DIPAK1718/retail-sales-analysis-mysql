# Retail Sales Analysis Using MySQL

## Project Overview

This project analyzes retail sales transaction data using MySQL.  
 
The project focuses on data validation, exploratory analysis, and 
business-oriented SQL queries to understand sales, customers,
product categories, and transaction patterns.

## Tools  
  
- MySQL
- MySQL Workbench 
- SQL  
 
## Dataset 
 
The dataset contains retail transaction information including: 

- Transaction ID
- Sale Date
- Sale Time
- Customer ID
- Gender
- Age
- Category
- Quantity
- Price per Unit
- COGS
- Total Sale

- Monthly Sales Analysis

## Project Questions

The project answers business questions such as:

1. Sales made on a specific date
2. Clothing transactions during November 2022
3. Total sales by category
4. Average customer age for Beauty purchases
5. High-value transactions
6. Transactions by gender and category
7. Best-selling month
8. Top 5 customers
9. Unique customers by category
10. Orders by time shift

Additional analysis includes:

- Categories above a sales threshold
- Customers spending above average
- Second-highest transaction
- Transaction ranking
- Top transactions by category
- Monthly sales
- Monthly sales comparison
- Sales growth
- Customer segmentation
- Most popular category
